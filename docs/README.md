# Documentation

Two files belong in this folder, with these exact names.

## docs/architecture.md

The architecture note, committed by **week 7**. One page:

- **The shape** — the major pieces, and how one request moves
  through them from entry to result.
- **The data** — what you store, in what form, and where it lives while the
  program runs. Say what survives a restart, if anything.
- **Three decisions** — three choices where a sensible alternative existed. For
  each: what you chose, what you rejected, and why. "It was the first thing I
  found" is a real reason; write it if it is true.
- **What is not built yet** — the parts of the project description you have not reached. This
  is why the note is due in week 7 rather than week 14, and it is the most
  useful section in it for both of us.

## docs/report.docx

The written report, at the end of the semester, with exactly this name:

    docs/report.docx

Lower case, `.docx` extension. The automatic check looks for the report at this
path and nowhere else: a file named anything else, or left in the repository
root, counts as not submitted.

The report is **not** uploaded to Virtual Campus. There you submit only the
link to this repository and the link to the published image.
